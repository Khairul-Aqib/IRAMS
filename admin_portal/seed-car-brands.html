CarBrands Bulk Seeder

Local one-shot tool. Paste a JSON object, click upload. Writes CarBrands/{brand} with a CarTypes array AND a Models subcollection (one doc per model).

Expected JSON shape (click to expand) 
{
  "Toyota": ["Vios", "Hilux", "Camry"],
  "Honda":  ["Civic", "City", "CR-V"],
  "BMW":    ["M3", "X5", "320i"]
}

Brand keys become document IDs. Each model becomes both an array entry on the brand doc and a separate document under CarBrands/{brand}/Models/{model}.
